# 인터넷 공개 멀티플레이 배포

이 프로젝트는 브라우저 클라이언트 + Node.js WebSocket 서버 구조다.
따라서 인터넷에서 여러 사람이 들어오려면 Node 서버가 공개 URL을 가져야 한다.

## 가장 간단한 배포 구조

1. 이 폴더를 GitHub 저장소에 올린다.
2. Node.js 서비스를 제공하는 호스팅에 저장소를 연결한다.
3. `npm install` → `npm start`로 실행한다.
4. 서비스가 발급한 HTTPS 주소를 친구들에게 공유한다.

서버는 `PORT` 환경변수를 사용하고, WebSocket은 페이지가 HTTPS면 자동으로 `wss://`를 사용한다.

- 비공개 방/초대코드
- 재접속 처리

- 치팅 방지
- 채팅 필터
