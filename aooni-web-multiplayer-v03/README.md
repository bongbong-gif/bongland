# 아오오니 감염모드 — Web Multiplayer v0.2

이 버전은 업로드된 스타크래프트 SCX를 별도의 브라우저 게임으로 재구축하기 위한 테스트용 멀티플레이 실행본이다.

## 1. 준비물

Windows 기준으로 Node.js LTS를 설치한다.

설치 후 이 폴더에서 PowerShell 또는 명령 프롬프트를 연다.

```bash
npm install
npm start
```

브라우저에서 아래 주소를 연다.

```text
http://localhost:8080
```

## 2. 혼자 테스트

1. 닉네임을 입력한다.
2. `방 만들기`를 누른다.
3. 방장이 `게임 시작`을 누른다.
4. WASD로 이동한다.
5. 방향키를 누르면 해당 방향으로 공격한다.
6. R은 재장전, K는 스킬 이벤트다.

## 3. 같은 집/같은 Wi-Fi에서 2인 테스트

서버를 실행한 PC에서 Windows 명령 프롬프트에:

```bash
ipconfig
```

IPv4 주소를 확인한다. 예: `192.168.0.10`

다른 PC에서는:

```text
http://192.168.0.10:8080
```

으로 접속한다.

방장 PC에서 `방 만들기`를 누르고 표시된 6자리 방 코드를 다른 플레이어에게 알려준다. 다른 플레이어는 같은 서버 주소로 들어와 `방 참가`를 누르면 된다.

Windows 방화벽이 Node.js의 네트워크 접근을 막으면 개인 네트워크에서 허용한다.

## 4. 인터넷에서 같이 플레이

현재 버전은 서버가 실행된 PC가 게임 서버다. 따라서 인터넷 플레이에서는 서버 PC의 8080/TCP를 외부에서 접근 가능하게 하거나 VPS/클라우드에 서버를 배포해야 한다.

공개 배포 전에는 인증, 비밀번호/초대 코드, 속도 제한, 치팅 방지 등을 추가하는 것을 권장한다.

## 6. 아직 임시인 부분

`shared/game-config.json`의 캐릭터별 능력치와 일부 전투 수치는 정확한 원본 수치가 아닌 프로토타입 값이다.

업로드된 SCX는 MPQ v1 구조이며, 내부에서 다음 항목까지 정확히 확인했다.

- `staredit\\scenario.chk`가 존재
- `scenario.chk` 블록 인덱스: 0
- 압축 전 크기: 10,900,359 bytes
- MPQ 저장 크기: 680,296 bytes
- 블록 플래그: `0x80010200`
- MPQ sector shift: 3
- MPQ sector size: 4,096 bytes
- hash table: 1,024 entries
- block table: 19 entries

다음 역분석 단계에서는 `scenario.chk`의 PKWARE DCL 섹터를 완전히 복원한 뒤 CHK 섹션에서 실제 위치/유닛/트리거/스위치/Deaths/Score 등의 수치를 정규화한다.

## 7. 라이선스/권리

원본 맵의 그래픽/음원/캐릭터 이미지 등을 공개 웹게임에 그대로 배포할 권리는 별도로 확인해야 한다. 개발 테스트에서는 권리를 가진 리소스 또는 새로 제작한 리소스를 사용하는 것이 안전하다.
