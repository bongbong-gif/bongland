# 아오오니 감염모드 Web v0.4

원본 스타크래프트 유즈맵/참고 영상의 분위기에 맞춰 검은 배경, 붉은 테두리, 청록 점선, 회색 복도형 플레이 화면, 픽셀풍 캐릭터/HUD로 교체한 멀티플레이 프로토타입입니다.

## 목표
- 브라우저에서 접속
- 공개 방 목록에서 참가
- 최대 7명
- WASD 이동 / 방향키 공격 / R 재장전 / K 스킬 입력
- 실시간 WebSocket 동기화

## 주의
원본 맵의 모든 수치/트리거/그래픽을 완전히 복제한 버전은 아닙니다. 현재는 원본 스타일의 플레이 화면을 먼저 맞추는 단계이며, 다음 단계에서 실제 SCX 데이터 분석 결과를 규칙에 반영합니다.
